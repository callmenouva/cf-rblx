Privacy

This page describes how personal data of users is managed when using the Corsica Ferries RBLX website and ticketing system.

1. Fan-made Project

Corsica Ferries RBLX is an unofficial fan-made project and is not affiliated with Forship S.p.A. / Corsica Ferries – Sardinia Ferries. All content is created solely for entertainment and simulation purposes on the Roblox platform.

2. Data Controller

The data controller is the owner/manager of the Corsica Ferries RBLX project.

3. Data Collected

While using the website, non-identifiable technical information may be automatically collected, such as:

  1. anonymized IP address
  2. browser and device type
  3. technical data necessary for the operation of the website

When using the ticketing system, the following personal data may be collected:

  1. Discord username
  2. email address
  3. Roblox username
  4. technical identifiers related to the system (e.g. ticket ID)

4. Purpose of Data Processing

The collected data is used exclusively for:

  1. ticket generation and management
  2. user identity verification within the system
  3. prevention of abuse or improper use
  4. technical management and service security

Data is not used for marketing or profiling purposes.

5. Legal Basis

Data processing is based on:

  1. user consent given when using the ticketing system
  2. technical necessity for providing the requested service

6. Data Processing and Storage

Data is processed digitally through secure systems and stored on third-party platforms. Data is retained:

  1. for as long as necessary for the ticketing system to function
  2. or until the user requests deletion

7. Third-party Services

The project uses third-party services that may process personal data:

  1. Firebase (database and ticket system management)
  2. Google (cloud infrastructure)
  3. Discord Inc. (user identification)
  4. Roblox Corporation (username and platform)
  5. GitHub (website hosting)

8. Data Sharing

Personal data is not sold or shared with third parties. It is only processed by the technical services necessary for system operation.

9. User Rights

Users have the right to:

  1. access their data
  2. request correction
  3. request deletion
  4. restrict or object to processing

To exercise these rights, users can contact the project through the contact page.

10. Data Security

Appropriate technical measures are adopted to protect data from unauthorized access, loss, or disclosure.

11. Changes to this Policy

This privacy policy may be updated at any time. Changes will be published on this page.

12. Contacts

For any privacy-related request, users can use the website contact page.
